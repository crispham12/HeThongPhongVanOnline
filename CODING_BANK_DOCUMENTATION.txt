PHẦN 1 — TỔNG QUAN HỆ THỐNG
================================================================================

Chức năng "Ngân hàng Bài Coding & Practice Coding" bao gồm 2 phần chính:

  1. ADMIN: Quản lý ngân hàng bài coding (CRUD)
     - Chỉ Admin mới có quyền thêm / sửa / xóa bài coding
     - Tạo bài dạng LeetCode-style

  2. CLIENT: Luyện tập và đánh giá coding
     - User xem danh sách bài, lọc theo độ khó, role, category, skill
     - Workspace Monaco Editor tương tự LeetCode
     - Run Code (public test cases)
     - Submit Code (public + hidden test cases + AI review)
     - Xem lịch sử nộp bài
     - AI phân tích kỹ năng và lộ trình học tập

Tech Stack:
  - Backend  : ASP.NET Core Web API, Entity Framework Core, SQL Server
  - AI Layer : Python FastAPI, OpenAI GPT, subprocess (Python / Node.js executor)
  - Frontend : React, Monaco Editor (@monaco-editor/react), Axios

---- 6.4 Code Executor (coding_executor.py) ----

File: ai-service/utils/coding_executor.py

  Hàm execute_python(code, test_cases):
    - Phát hiện style: "function style" (có def) vs "script style" (stdin)
    - Trích tên hàm từ dòng đầu tiên có "def "
    - Function style: tạo runner gọi hàm với args từ input
    - Script style: mock sys.stdin = StringIO(input)
    - Tạo temp .py file, chạy subprocess với timeout 3 giây
    - So sánh output (normalize: bỏ spaces, brackets, quotes, lowercase)
    - Kết quả: PASS | FAIL | Timeout | Runtime Error

  Hàm execute_javascript(code, test_cases):
    - Phát hiện function style ("function " trong code)
    - Tạo temp .js file, chạy bằng "node" subprocess
    - Tương tự Python executor

  Hàm execute_code(language, code, test_cases):
    - Dispatcher chính
    - "python" → execute_python()
    - "javascript" / "typescript" → execute_javascript()
    - Java, C#, C++, ... → Simulation (mock pass nếu code > 40 ký tự)

  Bảo mật / Giới hạn:
    - Timeout 3 giây mỗi test case
    - Chạy trong temp file, xóa sau khi chạy
    - KHÔNG có sandbox network isolation (local dev only)

PHẦN 9 — LUỒNG XỬ LÝ HOÀN CHỈNH
================================================================================

---- 9.1 Luồng RUN CODE ----

  User viết code → nhấn [Chạy thử]
    ↓
  React: codingPracticeApi.runCode(id, {language, code})
    ↓
  ASP.NET: PracticeCodingProblemsController.Run(id, req)
    ↓
  PracticeCodingProblemService.RunCodeAsync()
    → Lấy PublicTestCases từ DB
    → POST /ai/practice/run gửi lên AI Service
    ↓
  Python FastAPI: /ai/practice/run
    → execute_code(language, code, publicTestCases)
    → Chạy subprocess Python/Node.js với timeout 3s
    → Trả [{testCaseIndex, input, expected, actual, status, passed, ms}]
    ↓
  ASP.NET: Map AiRunResponse → SubmitCodeResult
    → Status: Accepted nếu tất cả PASS, ngược lại Failed
    → AiFeedback: "Test 1: PASS - ..., Test 2: FAIL - ..."
    ↓
  React: Hiển thị trong Console Tab "Chạy thử"
  KHÔNG lưu DB

---- 9.2 Luồng SUBMIT ----

  User nhấn [Nộp bài (Submit)]
    ↓
  React: codingPracticeApi.submitCode(id, {language, code})
    ↓
  ASP.NET: PracticeCodingProblemsController.Submit(id, req)
    ↓
  PracticeCodingProblemService.SubmitAnswerAsync()
    → Lấy PublicTestCases + HiddenTestCases từ DB
    → POST /ai/practice/submit gửi lên AI Service
    ↓
  Python FastAPI: /ai/practice/submit
    → execute_code() tất cả test cases
    → Xác định status: Accepted | Failed | Timeout | RuntimeError
    → Gọi OpenAI: phân tích code quality
    → Build markdown feedback
    → Trả {status, passedCount, totalCount, score, timeComplexity, spaceComplexity, aiFeedback}
    ↓
  ASP.NET:
    → Tạo UserCodingPracticeHistory, lưu DB
    → Trả SubmitCodeResult với PracticeId
    ↓
  React: Hiển thị trong Console Tab "Kết quả nộp bài"
    → Status badge, Score, Complexity, AI Feedback

---- 9.3 Luồng PHÂN TÍCH KỸ NĂNG (Roadmap) ----

  User chuyển sang Tab "AI Roadmap & Skill Analysis"
    ↓
  React: codingPracticeApi.getSkillAnalysis()
    ↓
  ASP.NET: PracticeCodingProblemService.GetSkillAnalysisAsync()
    → Lấy toàn bộ UserCodingPracticeHistory của user
    → Nếu chưa có lịch sử → trả DTO mặc định "bắt đầu làm bài"
    → POST /ai/practice/analyze-skills gửi lên AI Service
    ↓
  Python FastAPI: /ai/practice/analyze-skills
    → Gọi OpenAI: phân tích weakness/strength/roadmap
    → Trả {weakSkills, strongSkills, overallAssessment, roadmapSteps}
    ↓
  React: Hiển thị Skill Badges + Roadmap timeline

PHẦN 12 — GHI CHÚ VÀ HẠN CHẾ
================================================================================

1. Code Executor Sandbox:
   - Python và JavaScript chạy trực tiếp bằng subprocess trên máy chủ
   - Chưa có network isolation / memory limit (phù hợp cho dev local)
   - Java, C#, C++ chỉ simulate (không chạy thực sự) vì cần compiler cài đặt
   - Timeout mặc định: 3 giây / test case

2. OpenAI API Key:
   - Cần OPENAI_API_KEY trong ai-service/.env để có AI review thực sự
   - Nếu thiếu key → trả mock feedback (hệ thống vẫn hoạt động bình thường)
   - Prompt AI viết bằng tiếng Anh, response trả về tiếng Việt

3. Phân trang Category:
   - CategoriesJson là JSON array lưu trong 1 cột
   - Filter theo category được xử lý in-memory (sau khi fetch từ DB)
   - Cần cải thiện nếu số lượng bài lớn (>1000 bài)

4. Random Problem (cho phỏng vấn):
   - GetRandomCodingProblemAsync() filter AllowRandomSelection=true
   - Filter skill cũng in-memory
   - Dùng Random.Next() (không có seed cố định)

5. Lịch sử nộp bài:
   - GetPracticeHistoryAsync() lấy TẤT CẢ bài của user (không phân trang)
   - Cần thêm phân trang nếu user có nhiều lần submit
